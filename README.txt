# NumPy Mini Project

## Project Title
Employee Skill Assessment & Job Role Recommendation System

## Objective
To develop a NumPy-based system that evaluates employee technical skills, calculates job role suitability scores, simulates performance improvements, and recommends suitable job roles.

## Technologies Used
- Python
- NumPy

## Dataset
- 8 Employees
- 4 Technical Skills
- 3 Job Roles

## Project Tasks
1. Employee Skill Data Management
2. Job Role Suitability Analysis
3. Performance-Based Bonus System
4. Skill Improvement Simulation
5. Random Performance Simulation
6. Individual Employee Evaluation
7. Recommendation and Business Insights

## How to Run
Install NumPy:
python -m pip install numpy

Execute:
python employee_skill_assessment.py

## Library Restriction
The complete implementation uses NumPy for numerical operations. No Pandas or Scikit-learn is used.
